# 成果報告規格

## 讀者與版面

兼顧課堂／專題與統計諮詢。PDF 採諮詢書面報告風格：醒目結論、大圖、短段落；未指定封面、配色或字型不得宣稱是使用者指定。內附 render 程式採可修改的白底、深色標題與青綠重點作預設。Markdown 與 PDF 來自同一內容結構，保持實質一致。

## 必要順序

1. 研究問題：背景、觀測單位、Y／X、目的；未知資訊明確標示，不編造來源或幣別。
2. 重點結果與建議：先回答問題、量化關鍵結果，說明建議適用前提；未提供成本／容許誤差時不宣稱模型可部署。
3. 資料與方法：樣本數、缺失與處理筆數、模型選用理由、資料切分、CV 與參數搜尋；正文白話解釋。列出各變數的缺失筆數與比例、實際採用的處理方式，以及處理前後的樣本數與變數數。若有插補，須列明插補變數、方法、實際插補筆數及使用的中位數；若有刪除變數，須列明變數、缺失比例、刪除理由與使用者確認紀錄。數值型 X 缺失比例 ≤20% 時預設建議中位數插補；>20% 時經使用者確認後才刪除變數。類別型 X 與缺失 Y 另列已確認的處理方式，不套用數值型 X 的中位數插補規則。
4. EDA 探索性資料分析：呈現前處理後、判斷 Y 類型及模型推薦前執行的探索結果，包括描述統計、前處理前後缺失概況、適用數值變數的箱形圖與直方圖。依資料類型補充類別次數圖、散佈圖及相關性熱圖，附白話解讀，說明分布、偏態、可能離群點與變數關係，以及對後續模型推薦的意義。離群點不自動刪除；不適用的圖表說明原因。
5. 模型結果與診斷：關聯解釋與預測分別呈現。清楚標明係數的資料範圍、尺度與類別基準；區分訓練、選模 CV、保留測試；不使用顯著／不顯著語句。
6. 限制：遺漏因素、代表性、模型形式、未檢查事項、適用邊界；避免因果宣稱。若有缺失或插補，說明缺失機制的不確定性，以及插補可能影響分布、變異與變數關係的限制。
7. 附錄：本次使用方法的公式與技術細節、已產生的完整診斷圖、正文未呈現的 EDA 圖、精簡可靠來源、版本、資料雜湊與重現指令。
8. 完整 Python 程式碼：放最後，列出每個檔名與全部程式；不能用「其餘省略」或未提供的自訂工具代替。包含本次實際使用的缺失比例計算、插補、經確認的變數刪除、EDA 描述統計與全部 EDA 圖表繪製程式，並能重現報告中的處理紀錄、數值與圖表。

## 圖表

正文只選能回答研究問題、解釋模型或揭露重要問題的圖。每張有樣本範圍、單位／軸標籤與白話解讀。EDA 圖須標示資料是否經插補；額外 EDA 與診斷圖放附錄。類別型結果至少提供混淆矩陣；表格列為實際、欄為預測，0／1 對應與正類清楚標示。

## 重現合約

- 資料經檔案路徑匯入；程式開頭集中設定資料路徑、Y／X、輸出位置、seed 與已同意方案，包括插補方式及經確認刪除的變數。
- 一次執行重現全部數值、模型、圖表及 PDF／Markdown。允許多個同目錄模組，但必須全部交付並附在報告末尾；只需一個入口命令。
- 重現流程須包含缺失檢查、實際採用的插補與變數刪除、EDA 描述統計、箱形圖、直方圖及其他已納入報告的 EDA 圖。未採用的插補或刪除程序不得在重跑時自動啟用。
- 預測評估中的中位數等前處理參數只以訓練資料估計，再套用驗證或測試資料；CV 每一折皆重新估計。報告須標明插補參數的估計範圍；若各折中位數不同，程式須可重現其紀錄。會影響選模的 EDA 以訓練資料為依據。
- 附實際套件版本、鎖定依賴、安裝與執行指令；原始資料不必內嵌，需保留相同內容並記錄雜湊。
- 不在重跑時自行選新分析方案。隨機種子固定；浮點、字型與平台差異須註明，不承諾 PDF 逐位元一致。
- 程式遇路徑／欄位錯誤即停止；依賴缺少、無法估計或未收斂明確報錯。不得僅產出部分檔案就稱 PDF 與 Markdown 皆已成功。
- 原始教材保留推論內容供參考，但本次預設報告不含 CI、p-value、BP／JB、穩健標準誤或 Bootstrap。
