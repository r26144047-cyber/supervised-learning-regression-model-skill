# 成果報告規格

## 讀者與版面

兼顧課堂／專題與統計諮詢。PDF 採諮詢書面報告風格：醒目結論、大圖、短段落；未指定封面、配色或字型不得宣稱是使用者指定。內附 render 程式採可修改的白底、深色標題與青綠重點作預設。交付 Quarto 原始檔 `report.qmd` 與由其渲染的 `report.pdf`，兩者來自同一內容結構，保持實質一致。維持既有白底、深色標題、青綠重點、大圖與短段落的版面風格，不另行改版；QMD 設定與 PDF 排版須一致。

## 必要順序

1. 研究問題：背景、觀測單位、使用者勾選並確認的 Y（單選）／X（多選）、時間或群組／重複測量結構、目的；未知資訊明確標示，不編造來源或幣別。
2. 重點結果與建議：先回答問題、量化關鍵結果，說明建議適用前提；未提供成本／容許誤差時不宣稱模型可部署。
3. 資料與方法：樣本數、缺失與處理筆數、模型選用理由、AIC 選模與參數搜尋（全程不使用交叉驗證）；正文白話解釋。列出各變數的缺失筆數與比例、實際採用的處理方式，以及處理前後的樣本數與變數數。若有插補，須列明插補變數、方法、實際插補筆數及使用的中位數；若有刪除變數，須列明變數、缺失比例、刪除理由與使用者確認紀錄。數值型 X 缺失比例 ≤20% 時預設建議中位數插補；>20% 時經使用者確認後才刪除變數。類別型 X 與缺失 Y 另列已確認的處理方式，不套用數值型 X 的中位數插補規則。
4. EDA 探索性資料分析：先記錄選定 Y／X 後、前處理前進行的離群候選值檢查（箱形圖、IQR、散佈圖），包括筆數、識別碼、查核結果與經確認的處理方式，不將極端值直接判定為錯誤。呈現前處理後、判斷 Y 類型及模型推薦前執行的探索結果，包括描述統計、前處理前後缺失概況、適用數值變數的箱形圖與直方圖。依資料類型補充類別次數圖、散佈圖及相關性熱圖，附白話解讀，說明分布、偏態、可能離群點與變數關係，以及對後續模型推薦的意義。離群點不自動刪除；不適用的圖表說明原因。
5. 模型結果與診斷：關聯解釋與預測分別呈現。清楚標明係數的資料範圍、尺度與類別基準；標明建模資料範圍；AIC 與訓練誤差不得稱為獨立預測評估。不安排交叉驗證，也不新增保留測試集最終評估步驟。係數解釋不使用顯著／不顯著語句。
   - 連續 Y 推薦 Linear／Polynomial／Ridge／Lasso；二元 Y 推薦 Logistic，必要時評估懲罰式 Logistic。記錄候選模型支援範圍與使用者確認結果，不套用連續模型的常態誤差假設於 Logistic。
   - Linear／Polynomial 必須呈現線性設定、異質變異數、獨立性與常態性診斷：殘差圖、適用的 BP／White、DW／BG、Q–Q 圖及 Shapiro–Wilk／JB 等結果。依適用條件選擇，不要求每項檢定全部執行；未計算者說明原因。檢定可呈現統計量與 p-value，以 0.05 作輔助判斷；不把 p≥0.05 當成假設已成立，不將無自相關視為完全獨立。不要求額外補查學生化殘差、槓桿值與 Cook’s distance。
   - 若異質變異數或常態性有重要問題，先查核資料與模型設定；Y 全為正值時提出 Box–Cox 建議，經確認後估計轉換參數、重新擬合並重查三項假設。說明轉換前後結果、係數尺度與預測回轉影響。Box–Cox 參數與正規化強度分別記為 lambda_BC 與 lambda_reg；不擅自加常數。Box–Cox 不能直接解決誤差相依性。
   - 轉換不適用、使用者不同意或一次合理修改後仍有重要問題時，不反覆轉換直到檢定通過。依原因提出 WLS／GLS、相關誤差模型、混合模型、GEE、穩健迴歸或適當 GLM 等替代方向，說明理由，明確標示「此方法不在本 Skill 支援範圍內，本 Skill 不執行其擬合與調參」，停止自動修正並保留已完成結果及限制。
   - 概似與比較條件適用且使用者確認後，呈現候選模型／次數／lambda 的 AIC、有效自由度、相對最小 AIC 的差值與選定理由；選 AIC 最小者。Ridge／Lasso 使用有依據的有效自由度近似 AIC，不能直接計算全部係數；懲罰式 Logistic 未有適用實作時說明不支援。候選模型須使用相同 Y、相同觀測值與一致概似尺度；Box–Cox 比較須納入 Jacobian 及轉換參數複雜度。異質或相依問題未妥善處理時，不以不適用的獨立同質 Gaussian 概似強行比較；穩健標準誤不能修正該概似。選模後更新最終診斷，有問題時依支援邊界回報。
6. 限制：遺漏因素、代表性、模型形式、未檢查事項、未改善的假設問題、AIC 近似與選模不確定性、未做獨立預測評估及 Skill 支援邊界；避免因果宣稱。若有缺失或插補，說明缺失機制的不確定性，以及插補可能影響分布、變異與變數關係的限制。
7. 附錄：本次使用方法的公式與技術細節、已產生的完整診斷圖、正文未呈現的 EDA 圖、精簡可靠來源、版本、資料雜湊與重現指令。
8. 完整 Python 程式碼：放最後，列出每個檔名與全部程式；不能用「其餘省略」或未提供的自訂工具代替。包含本次實際使用的缺失比例計算、插補、經確認的變數刪除、EDA 描述統計、全部 EDA 圖表繪製程式、實際診斷、經確認的 Box–Cox、AIC 計算與參數搜尋程式，並能重現報告中的處理紀錄、數值與圖表。

## 圖表

正文只選能回答研究問題、解釋模型或揭露重要問題的圖。每張有樣本範圍、單位／軸標籤與白話解讀。EDA 圖須標示資料是否經插補；額外 EDA 與診斷圖放附錄。類別型結果至少提供混淆矩陣；表格列為實際、欄為預測，0／1 對應與正類清楚標示。

## 重現合約

- 資料經檔案路徑匯入；程式開頭集中設定資料路徑、Y／X、輸出位置、seed 與已同意方案，包括插補方式及經確認刪除的變數。
- 一次執行重現全部數值、模型、圖表、`report.qmd` 與由其渲染的 `report.pdf`。使用同一份結果資料產生正文與表格，不手動填入不一致的數字。允許多個同目錄模組，但必須全部交付並附在報告末尾；只需一個入口命令。
- 重現流程須包含缺失檢查、實際採用的插補與變數刪除、EDA 描述統計、箱形圖、直方圖及其他已納入報告的 EDA 圖。未採用的插補或刪除程序不得在重跑時自動啟用。
- 插補、標準化、轉換與 AIC 搜尋均明確記錄建模資料範圍與估計參數；比較模型使用相同觀測值，不因各候選模型自行刪除缺失或離群值而改變樣本。全程不執行 K-fold、LOOCV、GCV、巢狀交叉驗證或一個標準誤選擇準則。
- 附實際套件版本、鎖定依賴、安裝與執行指令；原始資料不必內嵌，需保留相同內容並記錄雜湊。
- 不在重跑時自行選新分析方案。隨機種子固定；浮點、字型與平台差異須註明，不承諾 PDF 逐位元一致。
- 程式遇路徑／欄位錯誤即停止；依賴缺少、無法估計或未收斂明確報錯。不得僅產出部分檔案就稱 QMD 與 PDF 皆已成功。
- 不預設報告係數 CI 或係數 p-value；假設診斷所需的檢定與 p-value 依上述規格呈現，取代舊版不含 BP／JB 的限制。穩健標準誤或 Bootstrap 不自動執行。
- Quarto、PDF 引擎、中文字型與圖檔依賴須列入重現環境；沿用原有樣式設定，確保中文、公式、表格與程式碼可正常渲染。交付前檢查 PDF 無缺字、截斷或超出版面；若 PDF 渲染失敗須明確回報，不得僅將副檔名改成 PDF。
