# regression-model-skill

一個以繁體中文互動的迴歸分析 skill：帶使用者從 CSV／Excel 原始資料，走到模型選擇、分析解讀與可重現報告。

先確認研究問題與 Y／X，再檢查資料、確認缺失值處理，完成 EDA 探索性資料分析後推薦模型。模型與調參方案經使用者確認後才執行，不自行刪除變數、改模型或擴大參數搜尋。

**主要流程：資料確認 → 資料檢查 → 確認前處理 → EDA → 判斷 Y 類型 → 推薦並確認模型 → 擬合與評估 → 確認修正或調參 → 成果報告。**

## 涵蓋的模型

| 方法 | 適用情境 |
|---|---|
| Linear regression | 連續 Y，作為線性關係的基準模型 |
| Polynomial regression | 連續 Y，且資料呈現平滑曲線趨勢 |
| Logistic regression | 二元 Y，估計正類事件機率 |
| Ridge regression | 連續 Y，需收縮係數或改善共線性下的穩定性 |
| Lasso regression | 連續 Y，需收縮係數並精簡變數 |
| Ridge Logistic | 二元 Y，採 L2 懲罰的 Logistic |
| Lasso Logistic | 二元 Y，採 L1 懲罰的 Logistic |

五種主要方法，包含二元結果的兩種正則化延伸。其他 Y 型態會先說明支援範圍，不直接套用上述模型。

模型推薦會考慮研究目的、樣本數、參數數量、共線性與關係形狀，不只用單一門檻判定最佳模型。

## 缺失值處理

缺失比例以各欄位的「缺失筆數 ÷ 原始資料總筆數」計算。

| 情況 | 預設建議與確認方式 |
|---|---|
| 數值型 X 有缺失且比例 ≤20% | 建議中位數插補，納入完整前處理方案，確認後執行；恰好 20% 歸此類 |
| X 缺失比例 >20% | 列出變數、缺失比例與影響，經使用者明確同意後刪除變數 |
| 類別型 X 有缺失 | 另提眾數或「缺失」類別等方案供確認；數字編碼的類別也不使用中位數 |
| Y 有缺失 | 另行確認是否排除缺失 Y 的資料列或補收資料，不預設插補 Y |

使用者不同意刪除時，討論保留、補收資料或其他方案。所有實際處理都要記錄於報告。

預測評估的插補參數只從訓練資料估計；交叉驗證時每一折重新估計，避免資料洩漏。

## EDA 探索性資料分析

完成已確認的前處理後，先做 EDA，再正式判斷 Y 類型並推薦模型。

- 描述統計與前處理前後的缺失概況。
- 適用數值變數的箱形圖（box plot）與直方圖（histogram）。
- 依資料類型與研究問題補充類別次數圖、散佈圖與相關性熱圖。
- 白話解讀分布、偏態、可能離群點及變數關係。

離群點只標示與說明，不自動刪除。若保留測試資料，會影響選模的 EDA 使用訓練資料。

EDA 圖表與解讀納入報告；插補及 EDA 繪圖程式完整列入報告末尾，供重現。

## 環境準備與使用（Claude 付費版）

使用 Claude Pro、Max、Team 或 Enterprise 帳號，在 Claude 網頁版加入 skill，並直接在對話框輸入指令。此方式不需在自己的電腦安裝 Python 或執行終端機指令。

### 1. 上傳並啟用 Skill

1. 下載 `regression-model-skill-updated.zip`，保留 ZIP 格式。
2. 點選 **＋ → Create skill → Upload a skill**，上傳 ZIP。
3. 確認 `regression-model-skill` 已出現在清單中，並開啟啟用開關。

選單名稱依介面語言可能不同。操作依據：[Claude 官方 Skills 使用說明](https://support.claude.com/en/articles/12512180-use-skills-in-claude)。

### 2. 在對話框上傳資料並輸入指令

建立新對話，上傳要分析的 CSV 或 Excel，再貼上以下指令，將檔名及欄位換成自己的資料：

```text
/regression-model-skill 分析我上傳的data.csv。
```

建議同時說明研究背景、觀測單位、Excel 工作表、分析目的，以及是否有時間順序、群聚或重複測量。二元 Y 請提供 0／1 的意義與正類；數字編碼的類別 X 也請明確指出。

分析在 Claude 的執行環境進行；Claude 需依實際環境檢查套件與輸出能力。現有腳本的 PDF 功能限制見下方說明。

## 成果報告

成果以 `report.pdf` 與 `report.md` 呈現，內容保持實質一致。依最新報告規格，包含：

1. 研究問題。
2. 重點結果與建議。
3. 資料與方法，包括缺失比例、插補方法與筆數、實際中位數，以及經確認的變數刪除紀錄。
4. EDA 描述統計、圖表與白話解讀。
5. 模型結果與診斷，區分關聯解釋與預測評估。
6. 限制。
7. 附錄，包括必要技術細節、補充圖表、來源、版本與重現資訊。
8. 完整 Python 程式碼，包括缺失處理、插補、EDA 繪圖、模型估計與評估。

PDF 採醒目結論、大圖與短段落的諮詢簡報風格。每張圖標示資料範圍、軸標籤與已知單位；二元結果至少呈現混淆矩陣及正類、分類閾值。

報告中的程式須可重現實際分析；PDF／Markdown 自動產製，依最新確認的報告規格實作。
